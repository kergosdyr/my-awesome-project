# Blog Working Agreement

- Article writing and editorial changes authorize local drafts, checks, and previews. Use `WRITING.md` for article work.
- Publish or deploy editorial changes only when the user explicitly authorizes publication of the current draft. Earlier approval does not cover later material editorial changes; an explicit instruction to publish the current version is sufficient.
- Complete the reviewable draft before asking for any still-missing publication approval.
- Use the root `AGENTS.md` verification rules. A prose-only edit needs content/link review and an affected-page preview when layout may change; it does not automatically require every app's tests.

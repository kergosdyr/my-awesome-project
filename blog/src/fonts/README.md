# 조선일보명조

`ChosunNm.woff2`는 조선일보가 무료 배포하는 `조선일보명조` TTF를 웹용 WOFF2로 무손실 서브셋 변환한 파일입니다.

- 공식 배포 페이지: https://event.chosun.com/100/100font.html
- 원본 파일: https://fontdown.chosun.com/100/ChosunNm.zip
- 권리자: (주)조선일보사
- 사용 조건: 개인 및 기업 사용자에게 무료 제공되며 자유롭게 배포할 수 있습니다. 대가를 받고 복사·배포하거나 수정해 판매할 수 없고, 배포된 형태 그대로 사용해야 합니다.

이 프로젝트에서는 글 본문의 인용문에만 사용합니다.

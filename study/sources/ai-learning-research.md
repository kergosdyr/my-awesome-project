# AI 회상 튜터 학습법 — 제공받은 출처 목록

이 문서는 사용자가 2026-08-25에 제공한 조사문의 근거를 나중에 다시 찾기 위한 자료 인덱스다. 링크와 연구 요지는 제공된 글을 기준으로 옮겼으며, 이 저장소에서 원문을 독립적으로 재검증한 상태는 아니다. 블로그에 인용하기 전에는 원문에서 연구 대상, 측정 방법, 효과 크기, 한계를 다시 확인한다.

## 주장과 출처

| 학습 원리 또는 주장 | 제공된 출처 |
| --- | --- |
| 연습 테스트와 분산 학습은 높은 효용을 보이고, 단순 재독·요약은 상대적으로 약하다. | [Dunlosky et al. 학습 기법 리뷰](https://www.psychologicalscience.org/journals/pspi/1529100612453266/) |
| 교실 환경에서 퀴즈와 테스트를 통한 회상이 학업 성취를 높였다. | [Testing (quizzing) boosts classroom learning — PubMed](https://pubmed.ncbi.nlm.nih.gov/33683913/) |
| 온라인 강의 중간의 회상 질문이 딴생각을 줄이고 학습을 개선했다. | [Interpolated memory tests — PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC3631699/) |
| 영상 구간 사이에 관련 내용을 회상하면 이후 내용 학습에도 도움이 될 수 있다. | [Interpolated Retrieval of Relevant Material — PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC12109270/) |
| 녹화 강의를 반복 시청하는 것보다 회상 테스트가 지연 기억에 더 유리했다. | [Coursera video lectures testing effect — PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC4731506/) |
| 자기 설명을 유도하는 학습의 효과를 종합했다. | [Inducing Self-Explanation: a Meta-Analysis](https://doi.org/10.1007/s10648-018-9434-x) |
| 가드레일 없는 생성형 AI는 연습 성과와 독립 학습 성과를 다르게 만들 수 있다. | [Generative AI without guardrails can harm learning — PubMed](https://pubmed.ncbi.nlm.nih.gov/40560616/) |
| 능동적 질문, 단계별 지원, 즉시 피드백을 포함한 AI 튜터를 수업과 비교했다. | [AI tutoring outperforms in-class active learning](https://doi.org/10.1038/s41598-025-97652-6) |
| 학습 영상을 의미 단위로 나누는 segmenting effect를 종합했다. | [A Meta-analysis of the Segmenting Effect](https://doi.org/10.1007/S10648-018-9456-4) |
| 가드레일을 둔 생성형 AI 교육의 의미를 해설한다. | [Knowledge at Wharton 해설](https://knowledge.wharton.upenn.edu/article/without-guardrails-generative-ai-can-harm-education/) |
| worked example 이후 직접 문제 해결로 넘어가는 학습과 전이를 다룬다. | [The effect of worked examples](https://doi.org/10.1080/01443410.2023.2273762) |
| 분산 학습의 간격과 장기 기억에 관한 메타분석 자료다. | [Cepeda et al. distributed practice PDF](https://augmentingcognition.com/assets/Cepeda2006.pdf) |

## 블로그 초안 전에 다시 확인할 것

- 각 연구가 다룬 학습자, 과목, 영상 길이가 개발자 학습과 얼마나 비슷한가?
- 즉시 성과와 AI 없이 치른 지연 평가를 구분했는가?
- 효과 크기를 실제 공부 시간이나 면접 수행으로 과장해 해석하지 않았는가?
- `1 → 3 → 7 → 14 → 30일`은 운영상 시작점이지 연구가 보장한 유일한 최적 간격처럼 쓰지 않았는가?

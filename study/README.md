# Study — 블로그보다 먼저 쌓는 학습 기록

이 폴더는 완성된 글을 보관하는 곳이 아니다. 공부할 때 실제로 떠올린 내용, 틀린 설명, 질문, 실험 아이디어를 남겨 나중에 블로그 글의 근거로 쓰는 작업 공간이다.

## 핵심 원칙

1. 자료를 다시 보기 전에 먼저 기억나는 것을 쓴다.
2. AI는 첫 답을 대신 만들지 않고, 누락·오류·가정을 찾는 튜터로만 쓴다.
3. 정의보다 `어떤 문제인가 → 왜 이 선택인가 → 대안과 trade-off는 무엇인가`를 남긴다.
4. 한 번에 질문 하나만 다룬다. 답하기 전에는 정답이나 모범 답안을 보지 않는다.
5. 복습은 읽기가 아니라 다시 설명하기로 한다.
6. 블로그 후보는 이해한 내용보다 생각이 바뀐 지점, 실패, 실험 가능한 질문에서 고른다.

## 폴더 구조

```text
study/
├── README.md                 운영 원칙과 기록 방법
├── review-queue.md           다음 복습 일정과 상태
├── _templates/
│   ├── session.md            하루 학습 체크인 템플릿
│   └── topic.md              장기적으로 키울 주제 노트 템플릿
├── sources/                  나중에 다시 확인할 원문과 출처 목록
├── sessions/                 날짜별 원본 회상과 튜터 대화 요약
└── topics/                   여러 세션에서 다듬어진 주제별 이해
```

## 매일 진행하는 순서

### 1. 회상

자료를 닫고 2~5분 동안 기억나는 내용을 `sessions/YYYY-MM-DD.md`에 적는다. 기억나지 않는 부분은 채우지 말고 `모름` 또는 빈칸으로 남긴다.

### 2. 세 문장으로 구조화

- 이 개념은 어떤 문제를 해결하는가?
- 핵심 아이디어 또는 동작 원리는 무엇인가?
- 가장 중요한 trade-off나 실패 조건은 무엇인가?

### 3. 튜터 검증

튜터는 한 번에 질문 하나만 한다. 사용자가 답하기 전에는 요약이나 정답을 제공하지 않는다. 답을 받은 뒤에도 전체 강의를 새로 쓰지 않고 다음만 돌려준다.

- 사실과 다른 부분
- 빠진 가정이나 경계 조건
- 설명이 이름 나열에 그친 부분
- 다음에 답할 꼬리 질문 하나

### 4. 전이 연습

원래 자료와 표면이 다른 상황에서 같은 원리를 적용한다. 예를 들어 Kafka를 공부했다면 “Kafka의 정의” 대신 처리량, 순서, 중복, 장애 복구 조건이 바뀐 시스템 설계 문제로 설명한다.

### 5. 복습 예약

기본 간격은 `1일 → 3일 → 7일 → 14일 → 30일`이다.

- `기억남`: 다음 간격으로 이동한다.
- `부분 기억`: 현재 간격을 한 번 반복한다.
- `기억 안 남`: 1일 간격으로 돌아간다.

복습 날짜와 결과의 기준은 해당 `topics/*.md`의 frontmatter와 복습 기록이다. `review-queue.md`는 활성 주제 링크만 모으며 날짜를 중복해서 적지 않는다.

## 블로그 글감으로 승격하는 기준

다음 중 둘 이상을 만족하면 주제 노트의 `blog_seed`를 `ready`로 바꾼다.

- 내 말로 문제와 선택 이유를 설명할 수 있다.
- 대안 두 가지 이상과 선택 기준을 비교할 수 있다.
- 코드, 로그, 명령 또는 측정 결과가 있다.
- 처음의 오해와 수정된 설명이 남아 있다.
- 다른 시스템 설계 문제에 같은 원리를 적용해 봤다.

`ready`는 곧바로 글을 발행한다는 뜻이 아니다. `blog/drafts/`에서 별도 초안을 시작할 수 있을 만큼 재료가 모였다는 뜻이다.

## 튜터가 지켜야 할 규칙

- 먼저 “오늘 무엇을 공부했는지” 또는 가장 오래 밀린 복습 질문 하나를 묻는다.
- 사용자의 첫 회상을 절대 대신 작성하거나 보완해서 기록하지 않는다.
- 출처가 없으면 사실 검증을 했다고 말하지 않는다.
- 점수보다 설명의 변화와 남은 불확실성을 기록한다.
- 세션 종료 시에만 파일을 정리하고 관련 주제 노트의 다음 복습일을 계산한다.
- 사용자가 원하지 않으면 블로그 문체로 다듬지 않는다.
